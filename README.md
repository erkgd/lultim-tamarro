# L'Últim Tamarro

Un juego de supervivencia en tercera persona desarrollado en Unity donde encarnas a un personaje que debe sobrevivir en un mundo hostil.

## 🎮 Características

- **Sistema de Combate**:

  - Ataques cuerpo a cuerpo con sistema de knockback
  - Sistema de invencibilidad temporal
  - Efectos visuales y de partículas durante los ataques
- **Sistema de Movimiento**:

  - Movimiento fluido en tercera persona
  - Sistema de correr
  - Control de cámara intuitivo
  - Física realista con gravedad
- **Sistema de Enemigos**:

  - IA avanzada con patrullaje y persecución
  - Diferentes estados de comportamiento
  - Sistema de detección y ataque
  - Efectos de sonido y animaciones
- **Interfaz de Usuario**:

  - Menú principal con opciones de música
  - Sistema de vida y daño
  - Controles intuitivos

## 🎯 Controles

- **Movimiento**: WASD o Flechas
- **Atacar**: Click izquierdo
- **Correr**: Shift
- **Interactuar**: E

## 🚀 Requisitos

- Unity 2022.3 o superior
- Sistema operativo: Windows, macOS o Linux

## 🛠️ Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/lultim-tamarro.git
```

2. Abre el proyecto en Unity Hub
3. Abre la escena principal desde `Survival/Assets/Escenas/MenuInicial.unity`

## 🏗️ Estructura del Proyecto

- `Survival/`: Contiene el proyecto principal de Unity
  - `Assets/`: Recursos del juego
    - `Scripts/`: Código fuente
    - `Escenas/`: Escenas del juego
    - `OurAssets/`: Assets personalizados
- `backend/`: Servidor backend para funcionalidades online
  - `api/`: API REST
  - `db/`: Configuración de base de datos
